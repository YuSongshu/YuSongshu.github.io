文件读写基本操作

Author: 瑜淞蜀 Date: June 1, 2026  16:26:37 Category: python python基础语法

25_文件读写基本操作

文件分类

1.文本文件：py/txt/json

2.二进制文件：png/jpg/mp3/exe

文件基本操作

1.打开文件 open()

语法： f(文件对象) = open(“文件位置”)

文件位置

相对路径：有参照的路径，以当前文件位置为参照，要打开的文件位置在哪

绝对路径：从计算机硬盘开始，一直到需要打开的文件位置

使用绝对路径时，为了避免\和后面的数字以及字母混杂在一起，需要使用r(原生字符)

但也可以在\前加一个\，取消掉\的转义作用

输出

name=”文件路径”

mode=”访问模式”，默认情况下以只读模式’r’打开文件

encoding=”编码格式”，默认情况下，以cp936编码格式打开文件

距离远用绝对路径

距离近用相对路径

加入参数，改变默认参数

open(name=”文件路径”, mode=”访问模式”, encoding=”编码格式”)

访问模式

r/w/a/+

r:只读模式，打开文件后只能读取文件中的内容

w:只写模式，打开文件后只能往文件中写入内容(数据的覆盖)（本质：以w 模式打开会清空文件）

a:追加模式，在文件末尾追加新的内容

+:可读可写，既可以读取也可以写入(结合r/w/a使用)

注：

文本文件：r/w/a/+

二进制文件：rb/wb/ab/+

w模式下若无文件则创建文件

编码格式

GB2312/GBK：中文字符编码

UTF-8：可变长度的编码，最常用

2.对文件读写操作 read()/write()

读

read(n)

读取文件

n:表示读取的字符个数

seek(n)：重置文件指针到第n位置

n：大于等于0

常用seek(0)重置文件指针到开头位置

注：

输出

readline()

读取文件的一行内容

若加入数字参数则与read(n)相似但遇到换行就立刻停

输出

readlines()

与 readline()类似但输出的是数组

默认情况下或readlines(0)，读取文件中全部的行

输出

写

with 上下文管理器

进入 with 代码块：自动执行 打开 操作，退出 with 代码块：无论是否报错，都自动执行 关闭 操作

作用：

1.自动关闭文件 （不用写 f.close()）

2.即使报错，也能安全关闭（不会泄露资源）

3.代码更简洁、更安全

w模式

进行数据的写入，新数据覆盖旧数据

a模式

进行数据的追加，新数据追加到旧数据之后

+模式

w+：进行数据的写入和读取

r+：进行数据的读取和写入

3.关闭文件 close()

你打开文件后，系统会给它分配资源，用完必须关，否则：

1.文件一直被占用，删不掉、改不了

2.占用系统资源

3.数据可能没真正写入文件（丢失）
