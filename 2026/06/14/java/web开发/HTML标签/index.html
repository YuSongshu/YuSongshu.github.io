HTML标签

Author: 瑜淞蜀 Date: June 14, 2026  10:59:45 Category: java web开发

常用 HTML 标签

html:标记语言

初识

1. 标题

2. 段落标签

3. 链接（可点击）

注：

上者两种写法都能正常运行

区别

< p >作用：自动换行 + 上下留一点空隙

若不用< p >两个链接会挨在一起，不换行

4. 换行、分割线

注：

两个< p >的行间距要大于< br > 的行间距

5. 输入框（表单必备）

6. 按钮

核心属性

type

（默认为submit提交表单）

  • button：普通按钮，无默认行为，需 JS 绑定事件
  • submit：提交表单数据（默认值）
  • reset：重置表单为初始值

disabled：禁用按钮，不可点击

name/value：表单提交时的键值对

onclick：点击事件（内联写法，推荐用 addEventListener）

7. 表单（前后端交互核心）

8.link（小图标）

9. div（盒子，用来布局）

10.列表

ul（无序列表） ol（有序） li标签使用

<ul> unordered list 无序列表

内容无先后顺序，默认前面是实心圆点，多用于导航、菜单、清单、分类列表。

<ol> ordered list 有序列表

内容有先后步骤 / 排序，默认阿拉伯数字 1、2、3，用于步骤、排名、操作流程。

<li> list item 列表项

唯一列表内容容器，ul/ol 内部只能直接放 li，文字、图片、div、p 都要写在 li 里面。

11.表格

CSS设置 样式 宽度 等 内容
