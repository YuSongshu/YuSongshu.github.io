Java语言中工具类，传递文件，JavaWeb涉及到文件上传，IO流 完成操作

回顾

程序中如何存储数据，变量，数组，对象（类），集合保存数据，保存位置：计算机中，内存（运行的程序在计算机的内存）

内存：快，但是数据 清除，持久化数据，数据库 ，数据保存文件中 ，

java程序中，操作本地文件，代码 创建 删除 代码 程序中数据的写入 读取

数据库能欧存储文件，但是不建议存，查询，（优化查询性能）

数据库 列： blob 存储二进制数据

分类

  • Input ：输入，读数据，（读取）
  • Output：输出，写数据，（推送）

四大流：

  • 字节输入流：把磁盘（网络）中的数据，按照一个一个字节的单位读取到程序中
  • 字节输出流：把程序中的数据，按照一个一个字节的单位推送到 磁盘或网络中
  • 字符输入流：把磁盘（网络）中的数据，按照一个一个字符的单位读取到程序中
  • 字符输出流：把程序中的数据，按照一个一个字符的单位推送到 磁盘或网络中

write()方法

它和 read() 的返回值是配套的：read() 读出 0~255 的 int（文件末尾 -1），write(int b) 写入 0~255 的低 8 位。

方法 写入内容 典型用途
write(int b) 1 字节 单字节写入、写标记位
write(byte[] b) 整个数组 已知数据是完整缓冲
write(byte[] b, int off, int len) 数组一部分,从数组下标off 写 len 字节 文件复制（推荐）

注：
