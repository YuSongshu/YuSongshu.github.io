文件上传

Author: 瑜淞蜀 Date: October 15, 2026  21:42:21 Category: java web开发

29_文件上传

文件上传：用户本地电脑上的文件，通过网络发送到远程服务器并保存。

前端常见需求：注册时选择上传头像、上传附件等。

文件上传原理

依赖于表单、输入框，选择本地文件，提交，浏览器文件和数据一起发送，服务器，解码，提取表单文本，文件数据拿到保存到服务器上

两种实现方式：

方式 说明
form 表单上传 同步提交，页面跳转
AJAX 异步上传 无刷新上传（后面学习）

数据库与服务器文件系统的区别：小文件、频繁查询的数据适合放数据库；实际上传的文件一般保存在服务器磁盘，数据库只存路径。

注

form提交数据的话：要求：表单提交方式必须为 post

原因：文件是二进制大体积数据，只能放在 HTTP 请求体（body）里；而 GET 没有可用的请求体，他是拼接在 url 路径之中而url 路径是有限制的

要添加参数：enctype=”multipart/form-data”

enctype 打包方式 用在哪
application/x-www-form-urlencoded（默认） 名=值&名=值，特殊字符转义（空格→+，中文→%XX） 普通登录、搜索表单
multipart/form-data 按分段格式：每项一段，带边界分隔符 文件上传
text/plain 纯文本，几乎不用 调试

Commons 类库

jar 包：别人写好的 Java 类，导入项目即可使用。

核心两个 jar 包：

  • commons-fileupload（文件上传）
  • commons-io（文件读写工具）

四个核心类

类 作用
DiskFileItemFactory 磁盘文件项工厂 表单提交后，临时缓存数据
ServletFileUpload 服务文件应用上传 读取工厂缓存，解析上传数据
FileItemIterator 文件迭代器 服务文件应用上传得到文件迭代器的类，遍历数据的
FileItemStream 文件项流 每一项数据对应的流

前端

基本文件上传

只处理一个文件字段，保存到 Tomcat 运行目录的 img 下，完成后重定向回页面。

流程小结：

  1. 工厂 → 上传解析器 → 迭代器 → 文件项流
  2. openStream() 得到输入流，读上传数据
  3. getRealPath("img") 得到服务器保存目录
  4. 输出流写文件（循环 + 字节数组）
  5. 关闭流，重定向并带回文件名

注

String path = request.getSession().getServletContext().getRealPath(“img”);

拆开看是四步

步骤 方法 拿到什么
1 request 当前请求对象
2 .getSession() 当前用户的 HttpSession
3 .getServletContext() 整个 Web 应用的 ServletContext（应用上下文）
4 .getRealPath("img") 把虚拟路径 "img" 转成服务器磁盘上的真实绝对路径

img是提前创建好的，getRealPath("img") 只做路径翻译

表单字段 + 文件混合

一次提交可能包含普通字段和文件。用 isFormField() 区分：

  • 普通字段：字节流转字符流，再套缓冲流读取
  • 文件数据：保存到 img，文件名加上时间戳 + 随机数防止重名

关键 API

API 说明
iterator.hasNext() / next() 遍历每一项上传数据
stream.getFieldName() 表单的 name 属性
stream.getName() 上传的原始文件名
stream.isFormField() true 普通字段 / false 文件
stream.openStream() 打开该项的输入流
getRealPath("img") 服务器部署目录下 img 的绝对路径

注意点

  1. 表单编码：普通字段读取时要指定 utf-8，否则中文乱码。
  2. 资源关闭：输入流、输出流用完都要 close()（练习代码直接关闭；正式项目用 try-with-resources）。
  3. 文件重名：同一文件名会覆盖，用「前缀 + 时间戳 + 随机数 + 原文件名」处理。
  4. 保存路径：getRealPath 得到的是 Tomcat 部署目录，发布到服务器后路径会变；正式项目常配置固定上传目录。
  5. 依赖：项目需导入 commons-fileupload、commons-io（见 web/WEB-INF/lib 或模块依赖）。
  6. 请求方式：表单上传通常 POST；Servlet 里 doPost 转调 doGet 即可。

运行时jar包找不到

解决方案

Ctrl+Alt+Shift+S打开 Project Settings

左侧选择 Artifacts

界面分为左右两栏

  • 左侧（Output Layout）：打包输出结构（就是最终 war 里面的目录结构）
  • 右侧（Available Elements）：项目可用资源、依赖包

把外部 jar 添加进 WEB-INF/lib（重点！）

展开右侧 Available Elements → 找到你的外部库

选中 jar，右键 → Put into WEB-INF/lib 操作之后，左侧 Output Layout 的 WEB-INF/lib 下面就会出现这 3 个 jar。(双击jar包也行)
