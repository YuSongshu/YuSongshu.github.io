clipse 常用快捷键大全（高频 + 分类整理，新手必背）

一、编辑与代码编写（最常用）

  1. 代码补全 / 智能提示：Ctrl + Space（Windows/Linux）/ Command + Space（Mac）；冲突时可改 Alt + /
  2. 快速修复错误：Ctrl + 1（自动导包、补全方法、修异常，万能快捷键）
  3. 格式化代码：Ctrl + Shift + F（一键规范缩进、换行）
  4. 自动导包 / 清理无用包：Ctrl + Shift + O（Organize Imports，自动添加缺失、删除多余 import）
  5. 撤销 / 重做：Ctrl + Z / Ctrl + Y
  6. 复制行 / 删除行：Ctrl + Alt + ↓（复制当前行到下一行）；Ctrl + D（删除当前行）
  7. 移动行：Alt + ↑ / Alt + ↓（上下移动整行代码，无需剪切粘贴）
  8. 注释 / 取消注释：单行 Ctrl + /；多行 Ctrl + Shift + /（块注释）、Ctrl + Shift + \（取消块注释）
  9. 查找 / 替换：Ctrl + F（当前文件查找）；Ctrl + H（全局搜索，支持文件 / 类型 / 正则）
  10. 快速定位行：Ctrl + L（输入行号，直接跳转）

二、导航与查看（快速找代码）

  1. 打开类 / 文件：Ctrl + Shift + T（Open Type，搜 Java 类，支持模糊匹配）；Ctrl + Shift + R（Open Resource，搜所有文件：xml、properties 等）
  2. 查看方法 / 类结构：Ctrl + O（Outline，当前类的方法 / 变量列表，快速跳转）；Ctrl + F3（快速定位当前选中元素）
  3. 跳转定义 / 实现：F3（跳转到选中类 / 方法的定义）；Ctrl + T（查看类 / 接口的继承 / 实现层次）
  4. 返回上 / 下一个编辑位置：Alt + ← / Alt + →（跳转后快速返回，效率神器）
  5. 打开最近文件：Ctrl + E（弹出最近打开文件列表，快速切换）

三、调试与运行（开发必备）

  1. 运行程序：Ctrl + F11（运行上次配置）；Alt + Shift + X, J（直接运行当前 Java 类）

  2. 调试程序：F11（调试上次配置）；Alt + Shift + D, J（调试当前 Java 类）

  3. 调试常用

    ：

    • F5：Step Into（进入方法内部）
    • F6：Step Over（单步执行，不进入方法）
    • F7：Step Return（跳出当前方法）
    • F8：Resume（继续运行，直到下一个断点）
    • Ctrl + Shift + B：添加 / 取消断点

  4. 查看变量 / 表达式：Ctrl + Shift + I（Inspect，查看选中变量值）

四、重构与代码优化（高效改代码）

  1. 重命名：F2（重命名类 / 方法 / 变量，自动同步所有引用）
  2. 提取方法：Alt + Shift + M（选中代码块，提取为独立方法）
  3. 提取变量：Alt + Shift + L（选中表达式，提取为局部变量）
  4. 提取常量：Alt + Shift + C（提取为静态常量）
  5. 移动代码：Alt + Shift + V（移动类 / 方法到其他包 / 类）

五、窗口与视图（界面操作）

  1. 最大化编辑器：Ctrl + M（一键放大 / 还原代码编辑区）
  2. 关闭当前标签：Ctrl + W；关闭所有：Ctrl + Shift + W
  3. 切换视图 / 透视图：Ctrl + F7（切换视图）；Ctrl + F8（切换透视图：Java、Debug、Git 等）
  4. 打开控制台：Ctrl + Alt + C（快速调出 Console 控制台）

六、快捷键冲突与自定义

  • 常见冲突：Ctrl + Space 与输入法冲突 → 改 Alt + /（Window → Preferences → General → Keys，搜索 Content Assist 修改）
  • 自定义：Window → Preferences → General → Keys，搜索对应功能，修改 / 添加快捷键

高频必背精简版（记这 10 个足够日常）

  1. Ctrl + 1（快速修复）
  2. Ctrl + Shift + O（导包）
  3. Ctrl + Shift + F（格式化）
  4. Ctrl + D（删行）
  5. Alt + ↑/↓（移动行）
  6. F3（跳转定义）
  7. Ctrl + Shift + T（搜类）
  8. F2（重命名）
  9. Ctrl + M（最大化编辑区）
  10. F8（调试继续）
