常见验证码

图文验证码，滑块验证码，计算验证码，点选验证码(难)…

ddddocr

ddddocr 是一个由国人开发者开发的、专门用于识别各种验证码（Captcha） 的 Python 第三方库，它的功能非常实用、轻量、高效，且对中文和常见验证码类型支持非常好

注：大批量文字别用

安装

注：python解释器版本要3.12 及以下

ddddocr常用API

功能 API 方法 参数 返回值 说明
初始化 OCR 对象 ddddocr.DdddOcr() 无 / 可选参数 OCR 对象 创建一个识别器
识别普通文字验证码 ocr.classification(img_bytes) 图片二进制数据 识别出的字符串（如 “1234”） 最常用！支持数字、字母、中文
识别滑块验证码 ocr.slide_match(bg, slide) 背景图 bytes、滑块图 bytes 滑动距离（像素 int） 用于滑块类验证码
目标检测（点选类） ocr.detection(img_bytes) 图片二进制 目标坐标等信息 用于点选类验证码（较复杂）

详细文档见 https://gitee.com/platformcn/ddddocr

ddddocr.DdddOcr()创建的识别器默认夹带私货（广告），通过参数可以去除
