fonttools

FontTools是一个Python库，它提供了一组用于操作字体的工具和API。这个库可以用来解析、 修改、创建和操作字体文件

使用

安装：pip install fonttools

导包：from fontTools.ttLib import TTFont

创建字体对象：font = TTFont(‘字体文件名’)

转换为稍微能看懂的东西（xml）：font.saveXML(‘字体文件名’)

获取映射关系（unicode 码点：字形名称）：maps = font.getBestCmap()

​ 得到的是字典对象

Pillow

Pillow是Python的一个第三方图像处理库，提供了广泛的文件格式支持和强大的图 像处理能力

使用

安装：pip install Pillow

导包：from PIL import Image, ImageFont, ImageDraw

​ Image: 图片、画布，ImageDraw：笔，ImageFont：字体

创建画布：img = Image.new(“模式”, (长, 宽), color=”背景颜色”)

创建画笔：draw = ImageDraw.Draw(img)

设置字体：font = ImageFont.truetype(字体文件位置, size=字体大小)

画图：draw.text((x, y), 内容, font=字体 ，font_size=大小, fill=’颜色’)

保存图片：img.save(“图片名称”)
