18反爬虫检测

Playwright虽然不用逆向，但还是要翻爬

测试网站：https://bot.sannysoft.com/

navigator.webdriver

navigator.webdriver：关键参数，如果是自动化打开浏览器其值是Ture

有些网站会检测其值实现反爬

解决方案

添加初始化脚本

大佬的js反爬文件

D:\tool\playwright进阶\素材\stealth.min.js

使用

启动本地浏览器

为什么要启动本地浏览器

无痕窗口：没有浏览痕迹

我们用脚本相当于无痕窗口，对于要登录的网站的数据采集，每次都要重新登录，所以我们启动本地浏览器就有浏览痕迹

注：

启动本地浏览器不要用你自己安装的浏览器【概率可行】，用 playwright 安装的

启动方式

playwright 打开

用户数据路径文件：C:\Users\AppData\Local\ms-playwright\chromium-1200\chrome-win64\data_001’（可以新建）

​ 用户数据不建议改

谷歌浏览器的路径：C:\Users\AppData\Local\ms-playwright\chromium-1228\chrome-win64\chrome.exe

subprocess 打开

subprocess是什么？

​ subprocess 是 Python内置模块，用来创建操作系统子进程，执行外部 exe、cmd、shell 命令。

原理：通过subprocess执行命令打开浏览器

示例

准备浏览器时会打开一个任务管理器（程序），goto时也会打开一个任务管理器，所以会有两个任务管理器

解决方案

注：默认 Chrome 用户配置文件夹，故不用user_data_dir=r’ 用户数据路径文件 ‘

动态id

以网易云评论为例

评论的xpath为//*[@id="2382397001785570199031"]/div[2]/div[1]/div/text()经过刷新，id 会变

所以要以标签定位//*[@class="cmmts j-flag"]/div

标签特点：翻页、刷新之都不变

或以a标签定位（点击的）
