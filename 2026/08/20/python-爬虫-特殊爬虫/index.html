CrawlSpider

CrawlSpider 是 Scrapy 框架提供的一个高级爬虫类，它封装了许多常见爬取网站 的逻辑，使得编写爬虫更加简单和快速，CrawlSpider 类继承自 scrapy.Spider 类，并额外提供了一些功能来处理网页链 接的跟踪和提取，并自动生成新的请求

对比项 普通 Spider CrawlSpider
链接提取 手动写 xpath/css 提取链接，手动yield Request() 通过Rule + LinkExtractor自动提取页面内链接，自动生成请求
主要用途 已知目标 URL，少量页面、定向抓取 全站爬取、递归爬网页、分页、整站采集
回调函数 parse()，自己解析、自己发请求 **不能重写 parse ()**，用rules里的callback做解析；parse 被父类占用做链接提取逻辑
分页处理 自己提取下一页链接，手动构造 Request 规则配置即可自动跟进下一页
灵活性 极高，完全自定义逻辑 受 Rule 规则约束，适合规则清晰的网站，复杂反爬 / 特殊逻辑不如普通 Spider 灵活

scrapy-redis

Scrapy-redis是一个用于Scrapy框架的Redis扩展，它可以将Scrapy的爬虫和中间件存储在 Redis中，以便于管理和控制爬虫的访问。
