18_函数

初识

函数：把某个功能代码加载到内存空间，绑定给函数名

作用：代码重用、便于代码管理和维护

注：

1.函数在定义时不会执行，只有在调用函数时才会执行函数体中的代码

2.执行顺序：在调用函数时，找到函数定义的位置，执行函数体中的代码

示例

pass 占位符

作用：暂时替代函数体代码，避免出现语法问题报错

Python 是缩进语法，很多代码块（如 if/for/def/class）后面必须跟至少一行缩进代码，否则直接报错

加 pass 就合法了

函数的参数

无参函数

使用场景：每次调用函数，执行的操作是固定的，更容易进行维护和测试，一般用于简单的打印；数据在函数内部进行输入

示例

有参函数

在定义是需要接收一个或读个形式参数，通过参数传递不同的值，可以控制函数的行为

在调用函数是，必须按照形式参数定义的个数、顺序进行传参

Python 没有传统意义上的函数重载（不像 C++/Java 那样同名不同参数自动区分）。

注

变相实现 “重载” 的三种办法：

1.给参数设默认值

2.可变参数 *args

3.用类型注解 + 判断类型

位置参数

在调用函数是，必须按照形式参数定义的个数、顺序进行传参

如果实际参数和形式参数个数不一致，会报错；如果顺序不一致，数据输出可能会混淆

返回值

指函数执行执行完成后，返回给函数调用者的数据

作用：

1.数据传递：通过返回值，将函数中的数据传递到调用函数的位置

2.控制流程：可以根据函数的返回值，决定程序的下一步操作

3.代码重用：将返回值传递给其它函数使用

返回值类型：数值型、字符串、列表、元组等

返回值的个数：没有返回值、一个返回值、多个返回值

一旦函数执行到return位置，函数停止运行，将返回值返回给函数调用者，return下方代码不会执行

注

函数中没有使用return，函数的返回值默认为None

多个返回值时以元组形式存放

作用域

概念：变量在程序中的可访问范围

python销毁机制：

在函数执行完成之后，函数内部定义的(局部)变量不再被保留，会被python垃圾回收机制自动清除。变量的使用仅限于函数内部，一旦函数执行完成，就会被销毁。

全局作用域

定义在函数外的变量，在当前的整个.py都可以使用(在函数中可以使用)

函数里可以直接读取 ，但不能直接赋值改，想修改必须加 global

​ 特殊情况：列表 / 字典。 但如果重新整体赋值，还是要 global

局部作用域

变量定义在函数内部，函数执行完成后被销毁

函数内部的变量只能在函数内部使用

如何在函数外进行使用？

1.将局部变量返回出函数，将函数的返回值存放在函数外的变量中

2.global将局部变量修改为全局变量

global 变量名1, 变量名2

本质是声明，要写在使用之前

嵌套的作用域

定义在嵌套函数中，变量的生效范围

nonlocal ：将内层变量修改为外层变量，只影响上一层，不能作为全局变量
