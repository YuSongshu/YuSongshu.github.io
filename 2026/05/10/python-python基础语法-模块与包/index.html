模块与包

Author: 瑜淞蜀 Date: May 10, 2026  15:31:25 Category: python python基础语法

20_模块与包

模块通常保存在.py文件中，每个文件定义了一个模块，文件名就是模块名

模块

模块导入

一般写在文件的开头，可以在文件任意位置使用

1.import 模块名1,模块名2 # 导入整个模块中的数据（可导入多个）

2.from 模块名 import 函数名 # 导入模块中指定的数据

3.import 模块名 as 别名 # 如果导入的模块名或函数名比较长，as取一个别名

4.from 模块名 import 函数名 as 别名

分类

内置模块：copy,random

第三方模块：pip install 模块名

自定义模块：.py文件

内置模块

随 Python 安装自带、无需额外pip安装的核心工具包

模块 核心用途 典型场景
os 操作系统交互（文件 / 目录 / 路径） 遍历目录、创建文件夹、路径拼接
sys 解释器与系统参数（命令行 / 路径 / 退出） 获取argv、修改sys.path、sys.exit()
datetime 日期时间处理（解析 / 格式化 / 计算） 时间戳转换、日志时间、倒计时
random 随机数与随机选择 生成随机整数、打乱列表、随机抽样
math 数学运算（三角函数 / 常数 / 对数） 平方根、π/e、sin/cos、阶乘
json JSON 序列化 / 反序列化 接口数据解析、配置文件读写
re 正则表达式匹配与替换 文本提取、手机号 / 邮箱校验
collections 高级数据结构（deque/Counter/defaultdict） 高效队列、计数统计、默认字典
time 时间访问与转换（延时 / 时间戳） time.sleep(1)、获取当前时间戳
logging 日志记录（分级 / 持久化） 程序运行日志、错误追踪

常用内置模块

random模块：提供了和随机数获取相关的方法

string：用于处理字符串相关的常量和工具的函数

第三方模块

由 Python 社区或其他开发者开发的模块，不是 Python 标准安装的一部分。

安装与使用方法：

通常使用包管理工具 pip 进行安装。

可以在命令行中运行 pip install 模块名

安装位置:pycharm终端/python解释器处打开cmd下载/cmd窗口/pycharm设置中的python解释器+号

国内源下载：pip install 模块名 -i 国内源地址

国内镜像源：

清华源： https://pypi.tuna.tsinghua.edu.cn/simple

阿里云源：https://mirrors.aliyun.com/pypi/simple

豆瓣源：https://pypi.douban.com/simple

中国科学技术大学源：https://pypi.mirrors.ustc.edu.cn/simple

腾讯云源：https://mirrors.cloud.tencent.com/pypi/simple

自定义模块

用户编写.py文件,在其它文件中使用(一个程序引用另一个程序的内容)(类似功能函数的封装)

导入模块后，可以使用模块中的数据和功能(函数)

注：

自定义模块和内置模块，以及第三方模块名，不能重名！！！！

脚本与模块

脚本：一个完整的程序，通常保存在.py文件中 （类似主函数）

模块：一个功能模块，通常保存在.py文件中，模块名与文件名相同 (类似功能函数的封装)

模块与脚本的区别：

模块：可以重复使用，模块名与文件名相同

脚本：只能运行一次，脚本名与文件名不同
