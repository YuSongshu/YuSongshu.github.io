字典

Author: 瑜淞蜀 Date: May 5, 2026  15:25:58 Category: python python基础语法

13_字典

字典是一种可变数据 <class ‘dict’>

格式：dict={key1:value1, key2:value2}

特点：

键值对存储

key的唯一性，不能重复，否则会进行数据的覆盖

key的数据类型必须是不可变

示例

定义空字典

1.直接定义一个空的花括号，表示为一个空字典

2.利用函数创建空字典

注：

为零为空的数据：整数零、浮点数零、复数零、空字符串、空列表、空元组、空字典、空集合、None

应用

通过字典存储学生信息，通过学生姓名，输出学生的所有个人信息

字典的增删改查

查

字典的元素查找，是根据字典的key，不能根据索引值查找

1.字典.get(key)

作用：通过key查找字典的value，查找的key不存在，返回None

输出

2.字典[key]

语法格式：字典[key] = value

作用：查找的key不存在，提示key不存在，代码报错

输出

改

1.字典[key] = 新数据

作用：通过key改字典中的值，用新数据覆盖旧数据

输出

删

1.del 字典[key]

注：

如果删除的key不存在，报错KeyError
如果删除整个字典，变量的引用也被删除

输出

2.字典.pop(key)

注：指定key删除字典中的键值对，如果删除的key不存在则报错

3.字典.clear()

作用：清除所有的键值对

输出

增

1.字典[新key] = 数据

作用：在字典中添加新的键值对

输出

2.字典.update(可迭代对象)

对于可迭代对象，必须包含二级元素，单个元素的长度是2，可以进行元素的拆分–key和value
可迭代对象：列表、元组、字典、集合
注：字符串不支持

直接修改原字典，不会返回新字典

其也可以用于更新（改）数据

作用：取出字典中所有的key

输出

字典.values()

作用：取出字典中所有的value

输出

字典.items()

作用：取出字典中所有的键值对

输出

意义

输出
