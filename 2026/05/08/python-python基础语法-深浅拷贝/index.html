深浅拷贝

Author: 瑜淞蜀 Date: May 8, 2026  21:02:47 Category: python python基础语法

17_深浅拷贝

赋值 = 引用指向

b = a：a 和 b 指向同一块内存，改一个另一个跟着变

浅拷贝 copy

只拷贝最外层，里面嵌套的子对象还是共用同一个

深拷贝 deepcopy

指创建一个新的对象，并且递归地复制原对象中包含的所有元素。层层全部拷贝，完全独立，改谁都互不影响

深浅拷贝的作用：备份数据 –> 针对可变数据

copy模块

浅拷贝

语法格式：新对象 = copy.copy(原对象)

创建新对象(新地址存放新数据)，但新对象中的元素地址和原对象中的元素地址是一样的

输出

查看内部元素地址

输出

内部元素的地址相同的

修改原数据中不可变元素，创建新对象

lst[0] = 200

修改可变元素时，因为地址相同(共有资源)，原始数据，备份数据没办法做到完全独立，不管修改哪一份数据，数据之间互相影响

输出

故使用场景：
需要对象副本、仅备份顶层结构、资源有限 / 追求性能时，优先用浅拷贝。

深拷贝

语法格式：新对象 = copy.deepcopy(原对象)

创建新对象，新对象中的元素地址和原对象中的元素地址是不一样的

输出

注

不可变元素地址完全不变，对应上文说的针对可变数据

修改可变元素

输出

修改原始数据与修改备份数据同理

可以证明原始数据和备份数据的完全独立

区别

浅拷贝 深拷贝
复制层级 仅顶层（第一层） 递归所有层级（全复制）
嵌套对象 复制引用地址，共享同一内存 复制完整内容，新内存、独立
修改影响 改嵌套对象，原对象跟着变 改任意层，原对象完全不变
性能开销 快、省内存 慢、耗内存（嵌套越深越明显）
典型场景 单层数据、简单结构、性能优先 嵌套复杂结构、需完全隔离数据
