类型转换

Author: 瑜淞蜀 Date: May 8, 2026  20:31:19 Category: python python基础语法

16_类型转换

1.int(x)：将数据x转换成整数

x:可以是浮点数/被引号包围的整数

注：

print(int(‘55.5’)) # 报错ValueError: invalid literal for int() with base 10: ‘55.5’

2.float(x)：将数据x转换成浮点数

x:可以是整数/浮点数/被引号包围的整数/被引号包围的浮点数

3.str(x)：将数据x转换成字符串

x:可以是任意数据类型

如果原先的数据带符号：列表、元组、字典、集合，转换成字符串后，符号也是字符串的一部分

res = str([12, 10, 55]) # str
print(res[0]) # 取字符串中第一个元素

单纯转换列表中的元素作为字符串

res2 = [str(i) for i in [12, 10, 55]]
print(res2)

将列表中的元素提取出来，作为字符串存放

res3 = “”.join(res2)
print(f”{res3=}”)

4.bool(x)：将数据x转换成布尔值

x:可以是任意数据类型

非零数据为真，数据为零或为空时为假

5.eval(x):将字符串两边的引号去掉，把中间内容作为python表达式执行

注：

eval()是存在安全风险的函数

与sql注入同理

6.ord(x)：将字符转换成ASCII码值(十进制数字)

7.chr(x)：将ASCII码值转换成字符

8.list(x)：将数据x转换成列表

x:必须是可迭代对象
可迭代对象：字符串、元组、集合、字典

输出

9.tuple(x)：将数据x转换成元组

x:必须是可迭代对象

10.set(x)：将数据x转换成集合

x:必须是可迭代对象

11.dict(x)：将数据x转换成字典

x:必须是可迭代对象,且元素长度为2

不包含字符串

总结

int():不能转换被引号包围的浮点数

str():在转换列表、元组、字典、集合时，符号也作为字符串的一部分

eval():存在安全风险的函数
