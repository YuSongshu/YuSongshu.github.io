24_多态

含义：不同类的对象使用相同的方法，得到不同的结果

优势：

提高代码复用性：可以编写通用的代码处理不同类型的对象

增强可扩展性：添加新的类不需要修改现有代码

提高可维护性：降低代码间的耦合度

增加灵活性：运行时可以动态决定具体调用哪个方法

python内置的多态实现

str + str 实现的功能：字符串的拼接

int + int 实现的功能：数字的相加

结论：不同类的对象，使用相同的操作方法+，得到不同的结果
