含义：单继承指一个子类(派生类)继承一个父类(基类)的所有属性和方法。

作用：通过继承，子类可以复用父类的代码，有助于减少代码冗余并提高代码的维护性。

重写

子类重新定义一个和父类同名的方法/属性，就会覆盖父类的版本，优先用子类自己的

作用：通过重写，子类可以给继承的方法提供自己新的实现功能

注：子类方法重写，必须定义一个跟父类同名、参数一致

super()重写

作用：重写不丢父类逻辑，还能加自己逻辑

与普通的父类名重写区别

1.父类名进行方法重写时，如果子类有多个父类，必须要具体指出是哪一个父类，写代码时容易混淆

2.super()进行方法重写时，不需要指明是哪一个父类，super()根据mro()继承顺序，来正确解析父类的方法，使代码更简单
