初识js逆向

在程序中，为了保护数据，通常会加密运输。加密操作通常是js代码实现，js逆向则是从加密的已知参数逆向找到它的位置

安装 node.js

Node.js 是一个基于 Chrome V8 引擎的 JavaScript 运行时环境，提供了执行和解释
JavaScript 代码的功能。

JavaScript是一种广泛使用的编程语言，常用于网页和网站的开发。
JavaScript的语法包括变量、数据类型、运算符、条件语句、循环语句、函数等基
本概念

执行js代码

Python 如果要执行JS代码，可以安装 PyExecJS。
安装：pip install PyExecJS
使用：

  1. 编译 js 文件
    execjs.compile()：编译 JavaScript 代码调用 js 中的方法
    参数：需要编译的 JavaScript 代码字符串
    返回值：JavaScript 运行的上下文
  2. context.call()：执行 JavaScript 代码中的函数，并返回其执行结果
    参数：
    • js 函数名称
    • js 函数参数…
    返回值：函数运行的结果

拓展（从文件读取 JS 代码）

异步请求

AJAX（Asynchronous JavaScript and XML）是一种在不重新加载整个网页的情况下，能够更新部分网页的技术。虽然名称中包含 XML，但现代的 AJAX 实现通常使用 JSON 或其他数据格式代替 XML。

原生 ajax

开始 ajax 请求的第一步创建一个 XMLHttpRequest 对象，这个对象是浏览器提供的 API，用于与服务器进行异步通信。

open()：设置请求类型（GET、POST等）、URL和是否异步执行；

setRequestHeader()：设置请求头；

send()：发送请求，该函数的参数是请求的参数。

jQuery ajax

‌jQuery AJAX‌ 是 jQuery 库提供的一组用于执行异步 HTTP 请求的方法，它封装了浏览器原生的 XMLHttpRequest 对象，简化了客户端与服务器之间的数据交互操作。

使用 jQuery ajax 时，需要先获取 jQuery 库，可以直接导入在线的 jQuery：

url：表示目标请求的 url。

type：表示发送请求的方式；

headers：表示设置的请求头；

success：表示请求成功后回调的方法。

注：

回调：
​ 回来调用
​ 对于发送请求来说：
​ 去：发送请求
​ 来【回来】：接收响应
​ 接收到响应数据之后要调用的函数。
​ 回调函数：回来的时候，调用的函数。
​ 干嘛？
​ 回来的函数处理响应的数据【解密、页面渲染】。
jQuery 是一个前端的库，这个文件一般不会随便修改里面内容。

Fetch API

Fetch API 提供了一种更简单、更强大的方式来进行 HTTP 请求，相比传统的 XMLHttpRequest 更加现代化和易于使用。
