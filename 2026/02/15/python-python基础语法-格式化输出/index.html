格式化输出

Author: 瑜淞蜀 Date: February 15, 2026  1:08:28 Category: python python基础语法

05_格式化输出——

1.%占位符

1.1 %d ：给整数占位

1.2 %f ：给浮点数占位

1.3 %s ：给字符串占位，通用的占位符(可以给任意的数据占位)

语法格式： print(“提示内容%d 提示信息%f 提示信息%s” % (整数, 浮点数, 字符串数据))

注:使用%f后，浮点数的精度会扩大，补全到六位小数

1.4 数据精度的控制–>四舍五入

格式：print(“提示内容%.nf” % 浮点数)

2.占位符使用不匹配

问题？身高的数据把浮点数的小数位，丢掉

问题？数字之间%d和%f可以互用，但存在精度丢失和精度的扩大；如果是字符串，只能用%s，否则会报错

3.%s通用的占位符

4.f表达式

4.1 格式：

print(f”提示内容{变量名}”)

f后，只有一个字符串数据。数据之间需要用逗号分隔开

不存在数据精度的丢失以及精度的扩展

4.2 数据精度的控制–>四舍五入

格式：print(f”{变量名:.nf}”)

4.3 支持对表达式进行操作

5.python内置函数，控制数据精度

5.1 round(变量名, n)

5.2 format(变量名,’.nf’)

6.输出对比

name = “小明”
age = 18
height = 177.6

①f表达式

print(f”我的名字是：{name}，年龄是：{age}，身高是：{height}”)

②占位符

print(“我的名字是：%s，年龄是：%s，身高是：%s” % (name, age, height))

③直接输出

print(“我的名字是：”, name, “，年龄是：”, age, “，身高是：”, height)
