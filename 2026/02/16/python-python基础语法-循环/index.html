循环

Author: 瑜淞蜀 Date: February 16, 2026  18:00:04 Category: python python基础语法

09_循环——

while循环

1. while循环（条件循环）

1.1 格式

while 判断条件:
​ 条件成立，对应的循环体
​ (判断条件中涉及到循环变量，对循环变量进行更新)

1.2 注意

判断条件中涉及到循环变量，注意对变量的定义，循环体中对循环变量进行更新
如果没有循环变量进行更新，循环是无限循环
写代码过程中，尽可能避免无限循环的无限循环

1.3 应用: 判断1~10之间的数字的奇数和偶数

2. debug调试

step over:一步步往下执行，不会进入到函数中(前期不涉及函数，主要用的功能)
step into：进入到函数中，设置跳转到源代码中
step into my code:只会进入到自己写的函数中
step out:跳出函数、

3. while无限循环

3.1判断条件中涉及变量，但是在循环体中没有对循环变量更新

3.2 直接在while后，写一个恒成立的True作为判断条件

使用场景：默认进入到循环中，循环次数无穷大的，只有满足指定条件，才会结束循环(break)

for循环

1. for循环(取值循环)

格式

for 临时变量 in 可迭代对象:
​ 循环体

常见的可迭代对象

列表

元组

字典

集合

字符串

生成器

文件对象

注：数值类型不是一个可迭代对象

2. range（）函数

用于创建一个表示整数序列的对象

range(起始值,结束值,步长)

默认的起始值为0
默认的步长为1
结束值必须要指定,且取不到结束值(包前不包后)

2.1 当步长为负数时，倒序取整数

2.2 应用

判断1~100的数字范围内的偶数个数,计算偶数的和

3. for循环的嵌套

类似if嵌套

循环的次数：外层循环*内层循环

for和while循环的区别

  1. 循环次数：
    for循环有固定的循环次数，常用于遍历可迭代对象
    while循环常用在循环次数不确定的场景中

  2. 终止条件：
    for循环将可迭代对象中的元素取完之后，循环结束
    while循环需要判断条件来决定循环什么时候结束

  3. 无限循环
    for循环不存在无限循环
    while存在无限循环

break和continue

1. break

作用：结束循环
应用：从苹果篮子中取苹果吃，吃到坏的苹果，终止吃苹果的动作

2. continue

作用：跳过某次循环，继续下一次循环
应用：从苹果篮子中取苹果吃，吃到坏的苹果，把坏苹果丢掉，继续吃后面的苹果

应用

随机数获取与猜测
