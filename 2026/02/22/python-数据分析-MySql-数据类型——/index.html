数据类型——

Author: 瑜淞蜀 Date: February 22, 2026  23:28:18 Category: python 数据分析 MySql

02数据类型——

数据类型在数据结构中的定义是一组性质相同的值的集合以及定义在这个值集合上的一组操作的总称

作用：

对数据进行统一的分类，从系统的角度出发是为了能够使用的统一的方式进行管理 ，更好的利用磁盘的空间。

MySQL把数据分成了三大类: 数值类型、字符串类型、时间和日期类型

数值类型

整数型

MySQL 为了更好的管理磁盘空间，有将整型分成五种子类型：

tinyint，smallint，mediumint，int，bigint

类型 存储字节 有符号范围 无符号范围 典型用途
TINYINT 1 -128 ～ 127 0 ～ 255 状态码、布尔标记、删除标识
SMALLINT 2 -32768 ～ 32767 0 ～ 65535 小计数器、年龄、门店库存
MEDIUMINT 3 -8388608 ～ 8388607 0 ～ 16777215 中型用户 ID、文章 ID、日订单量
INT 4 -2147483648 ～ 2147483647 0 ～ 4294967295 主键 ID、订单号、秒级时间戳
BIGINT 8 -9e18 ～ 9e18 0 ～ 1.8e19 分布式 ID、金融流水号、超大计数器

数值宽度显示

数据最终显示的位数。显示宽度没有特殊的含义，只是默认的告诉用户可以显示的位数而已，这是可以由用户来进行控制的。如果想要使用显示宽度，需要加zerofill 这个关键字

这种控制不会改变数据本身的大小，只是当位数不够的时候用 0 来填充

zerofill 作用：启用显示宽度的 0 填充效果，且自动隐含 unsigned（即加 zerofill自动变为 unsigned（不能存负数））

注：

数值超过显示宽度时，完整显示，不截断

无符号数值型

Mysql 中的 **数值类型 **全部默认都是有符号（正负符号）。 如果你的数据不需要使用负号进行显示，此时可以使用无符号的整数， 通过 unsigned即可表示无符号。

注：

仅数值类型支持 unsigned；字符串、日期等类型不支持

数据无需负数时，加 UNSIGNED 即可设为无符号，仅存非负数且数值上限翻倍。

小数型

在 MySQL 里面把小数型有分为了 浮点型 和 定点型 ：

浮点型： 小数点浮动，精度有限并且会丢失精度; (float/double)

定点型： 小数点固定，精度固定并且不会丢失精度； (decimal)
