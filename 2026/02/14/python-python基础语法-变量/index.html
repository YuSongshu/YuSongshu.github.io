03_标识符及变量

1. 标识符

1.1 概念：用来标识变量、函数、类等的名称

​ 变量名是标识符的一种

1.2 组成：

​ 数字、字母、下划线组成

1.3 开头：

​ 只能由字母、下划线，不能由数字开头

1.4 要求：

1.4.1 不能使用python的关键字作为变量名

​ 可以使用keyword模块查看当前版本的所有关键字：​

​ 原因：

​ 将关键字作为变量名，会覆盖掉关键字的原有功能

​ print()–>关键字–>作为变量名–>新数据覆盖旧数据–>print()函数原有的功能会消失

​ print = “hello world!”

​ print(print)

​ Python关键字按功能可分为以下几类：

​ 值关键字：如True、False、None，用于表示布尔值或空值。

​ 运算符关键字：如and、or、not、is、in，用于逻辑和对象操作。

​ 控制流关键字：如if、elif、else、for、while、break、continue，用于控制程序执行流

​ 程。

​ 函数与类相关关键字：如def、return、lambda、class、pass，用于定义函数和类。

​ 异常处理关键字：如try、except、finally、raise，用于捕获和处理异常。

​ 模块与作用域关键字：如import、from、as、global、nonlocal，用于模块管理和变量

​ 作用域控制。

​ 异步编程关键字：如async、await，用于定义和处理异步操作（Python 3.5+）。

​ 其他关键字：如del、with、yield、assert，用于资源管理、生成器和断言。

​

1.4.2 严格区分大小写

​ 虽然单词的意思一样，但是不同的变量名

​ name = “张三”
​ Name = “李四”
​ namE = “王五”
​ print(name, Name, namE)

1.5 命名规范：下划线命名法(变量名)、大驼峰命名法、小驼峰命名法

​ 下划线命名法(变量名)：单词之间，用下划线分隔开

​ student_score = 88

​ 大驼峰命名法；每个单词的第一个字母大写的，其它字母小写

​ StudentScore = 88

​ 小驼峰命名法：除第一个单词全小写外，其它单词的第一个字母还是大写

​ studentScore = 88

2.变量

​ 概念：是一个容器，计算机中的存储空间

2.1 作用

​ 临时保存运行的数据，在不同的代码中传递，记录程序运行的状态

2.2 变量的定义

创建变量：变量名 = 数据

使用数据，通过变量名

通过变量名，可以记录程序运行的值

1.3 一个变量被多次赋值

原则：新数据覆盖旧数据

2.4 变量的使用原则：先定义后使用

2.5 变量定义的规范性：

做到见名知意–>变量名和变量中存储的数据有关联性

​ 1. 不规范的使用

​ home = “苹果”

​ 正确的规范性使用

​ apple = “苹果”

​ 2.组成：数字、字母、下划线组成

​ name = “张三”

​ name_ = “张三”

​ name2 = “张三”

​ 3.开头：只能由字母、下划线，不能由数字开头

2.5.1 不能使用python的关键字作为变量名

2.6 注意点

变量使用时，不加引号！！！！！！

被引号包围的都是字符串，不是变量名
