01初识Mysql数据库——

数据库是按照数据结构来组织、存储和管理数据的仓库。是一个长期存储在计算机内的、有组织的、可共享的、统一管理的大量数据的集合。

数据库的分类

关系型数据库（SQL）：

Oracle、MySQL、SQLserver。

非关系型数据库（NoSQL: Not Only SQL）：

MongoDB、Redis。

关系型数据库 非关系型数据库
数据模型 固定二维表、行 / 列、Schema 严格 多模型（键值 / 文档 / 列 / 图）、Schema 灵活
一致性 强一致性（ACID） 最终一致性（BASE）为主
扩展性 垂直扩展为主（升级单机） 水平扩展为主（加节点）
查询语言 标准 SQL、支持复杂 JOIN 类 SQL / 专用 API，JOIN 能力弱
适用场景 事务强一致、复杂关联、金融 / ERP 海量数据、高并发、半结构化、灵活迭代
代表 MySQL、PostgreSQL、Oracle Redis、MongoDB、Cassandra、Neo4j
优点 易于维护，都是使用表结构，格式一致；使用方便，SQL语言通用，可用于复杂查询；支持SQL，可用于多个表间复杂的查询 格式灵活，存储数据的格式灵活；速度快，NoSQL可使用硬盘或随机存储器作为载体；成本低，nosql数据库部署简单，基本都是开源软件
缺点 固定的表结构，灵活度稍欠；传统关系型数据库来说，硬盘I/O是一个很大的瓶颈 不提供sql支持，学习和使用成本较高；不支持事务处理操作；数据结构相对复杂，复杂查询方面稍欠。

mysql基础知识

数据库对象

从宏观上可以将MySQL 服务器内部对象分成了四层: 系统(DBMS)、数据库(DB) [database]、数据表(Table)、字段(field) [column]。

SQL语言主要分为三个部分：

DDL（Data Definition Language）：数据定义语言，用来维护存储数据的结构（数据库、表），代表指令：create、drop、alter等。

DML（Data Manipulation Language）：数据操作语言，主要用来对数据进行操作（数据表中的内容），代表指令：insert、delete、update等。

DCL（Data Control Language）：数据控制语言，主要是负责权限管理（用户），代表指令：grant、revoke 等。

基本单位

user 用户 root

database 仓库

table 表 （存储数据的单位）

column 字段/列 （数据类型 大小 约束）

check 约束

​ 常用的有四种

​ 1.primary key 主键约束 效果 不能重复 不能为空 （一个表中只能有一个）

​ 2.unique 唯一约束 效果 不能重复

​ 3.not null 非空约束 效果 不能为空

​ 4.default 默认值约束 效果 不添加数据 数据库自动添加的数据

数据类型

类型 说明 常用场景 示例
INT 整数，最常用 ID、编号、年龄 sid INT
TINYINT 小整数 状态、性别、开关 status TINYINT
DECIMAL(M,D) 精确小数 成绩、金额 score DECIMAL(4,2)四位小数占两位
FLOAT 单精度浮点数（不精确） 一般不用 score FLOAT
DOUBLE 双精度浮点数（不精确） 一般不用 score DOUBLE
VARCHAR(n) 可变长度字符串 姓名、课程名、标题 sname VARCHAR(50)
CHAR(n) 固定长度字符串 固定长度内容 sex CHAR(2)
TEXT 长文本 备注、简介 remark TEXT
DATE 日期 生日、日期 birthday DATE
DATETIME 日期 + 时间 创建时间、操作时间 create_time DATETIME
