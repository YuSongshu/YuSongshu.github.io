27_Servlet

前端：展示数据

后端：处理数据 ， 业务逻辑 （如：登录的业务）

Java类，处理业务逻辑的地方，

Servlet

Servlet：普通的java类但是，继承或者实现接口的方式，拥有一个可以被访问的路径 地址

作用：控制器，负责接收请求、调用工具、跳转页面

Servlet创建方式两种：

  • 实现接口，拥有访问地址
  • 继承HttpServlet抽象类，拥有访问地址 ，更加灵活

Servlet配置 (两种任选其一)：

  • web.xml文件配置
  • @WebServlet注解配置（@单词 ，类似属性 ，比较直接，不用复杂的操作）
