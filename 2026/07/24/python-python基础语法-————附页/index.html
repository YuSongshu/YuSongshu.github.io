常用函数，方法及对应的应用

随机数获取与猜测

PyCharm Python 必备快捷键

一、导包 / 修复

  • 自动导包、快速修复：Alt + Enter
  • 优化导入（删无用包）：Ctrl + Alt + O

二、运行 / 调试

  • 运行当前文件：Shift + F10
  • 调试：Shift + F9
  • 停止运行：Ctrl + F2
  • 单行调试（下一步）：F8

三、代码快速编写

  • 代码补全：Ctrl + 空格
  • 向左进一个tab：Shift +Tab
  • 快速格式化代码：Ctrl + Alt + L
  • 复制一行：Ctrl + D
  • 删除一行：Ctrl + Y
  • 上下移动行：Alt + Shift + 上/下
  • 注释/取消注释：Ctrl + /

四、查找 / 跳转

  • 全局查找文件：Double Shift
  • 查找内容：Ctrl + F
  • 替换：Ctrl + R
  • 快速跳转到定义：Ctrl + 左键
  • 查找类/方法：Ctrl + Alt + Shift + N

五、重构 / 高效

  • 重命名：Shift + F6
  • 抽取方法：Ctrl + Alt + M
  • 快速包裹代码（if/for/try）：Ctrl + Alt + T

六、界面操作

  • 快速打开设置：Ctrl + Alt + S
  • 隐藏/打开侧边栏：Alt + 1
  • 快速回到编辑区：Esc

收缩当前函数 / 代码块：Ctrl + -

展开当前函数 / 代码块：Ctrl + +

文件内全部收缩所有函数：Ctrl + Shift + -

文件内全部展开所有函数：Ctrl + Shift + +
