Author: 瑜淞蜀 Date: March 22, 2026  8:27:19 Category: java 基础语法

语法

静态==类的 实例 == 对象的

static (背)

修饰成员变量 1.不带static的 实例成员

​ 2.带static的 静态成员/类成员

修饰普通方法 1.不带static的 实例方法

​ 2.带static的 静态方法/类方法

调用规则

在同一个类中的话 静态的方法只能调用静态的成员和其他静态的方法

​ 实例的方法什么都能调用

在不同类中 静态的公共资源可以使用类的名字直接调用

从内存分配的角度来讲

所有静态的公共资源类加载就会分配内存 （分配内存==初始化==加载）

一个类中如果静态的公共资源过多会导致类加载速度变慢（类变成重量级）

对象（背）

什么是对象==一种特殊的变量

1.数据类型特殊

​ 对象会使用自己的类名作为数据类型这是引用数据类型的一种==类类型==自定义类型

2.赋值方式特殊

​ 对象会使用new关键字加上类中的默认构造方法进行赋值

3.作用

​ 对象可以调用自己类中的公共资源在外部的类中进行使用

​ 对象.成员

​ 对象.普通方法()

公共资源交互方式(背)

一个类如果获取另一个类的公共资源

1.通过创建类的对象 %90 很常用

2.静态的公共资源可以通过类的名字直接调用 %5

3.继承

程序不同颜色的线 代表了不同的信息级别

1.正常的 info 黑色字

2.调试的 debug 调试级别

3.警告的 warn 警告的 黄线

4.严重的 error 错误的 红线

方法 （背 *）

类==地球 方法==一个一个国家

1.方法的设计

2.方法的参数和返回值

3.方法的调用

关键字

static 修饰成员变量和普通方法 表示静态的或类的

new 用来给引用数据类型赋值表示开辟一块独立的内存空间

访问权限关键字 一共是四个 表示公共资源受调用的范围

public 公共的

protected 受保护的

什么都不写 默认的

private 私有的
