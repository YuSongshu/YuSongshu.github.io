ArrayList

用前导包

import java.util.ArrayList;

语法（创建对象）：

ArrayList<数据类型> 变量名 = new ArrayList<>();

注：

泛型只能用包装类（Integer/String/Double等），不能用基本类型（int/char）

常用方法

增

list.add(“添加的元素”);

指定索引插入

list.add(1, “添加的元素”);

删

根据索引删除

list.remove(索引值);

根据元素删除

list.remove(“删除的元素”);

改

list.set(索引值, “修改的元素”);

查（通过索引）

list.get(索引值);

获取长度

list.size();

遍历集合

清空集合

list.clear();

判断是否为空

list.isEmpty();

判断是否包含元素

list.contains(“判断的元素”);

面向对象

声明 list 只能存对应的对象

List<创建的对象> list = new ArrayList<>();

本质：数据类型为创建的对象
