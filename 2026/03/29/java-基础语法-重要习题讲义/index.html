（1）. 写出sql语句，查询所有年龄大于20岁的员工（2分）

SELECT * FROM employee WHERE age > 20

（2）. 写出sql语句，查询所有年龄小于25岁的女性员工（3分）

SELECT * FROM employee WHERE age < 25 AND sex = ‘女’

（3）. 写出sql语句，统计男女员工各有多少名（3分）

SELECT sex,COUNT(NAME) FROM employee GROUP BY sex

（4）. 写出sql语句，按照年龄倒序获取员工信息（3分）

SELECT * FROM employee ORDER BY age DESC

（5）. 写出sql语句，获取员工中哪个姓名具有重名现象（3分）

SELECT NAME,COUNT(NAME) FROM employee GROUP BY NAME HAVING COUNT(NAME)>1

（6）. 写出sql语句，查询所有姓张的员工（3分）

SELECT * FROM employee WHERE NAME LIKE ‘张%’

（7）. 写出sql语句，查询住址为北京的前3条记录（3分）

SELECT * FROM employee WHERE address = ‘北京’ LIMIT 0,3

（8）. 写出sql语句，查询员工总数（3分）

SELECT COUNT(NAME) FROM employee

（9）. 写出sql语句，向表中插入一条记录（2分）

INSERT INTO employee (NAME,age,sex,address) VALUES (‘’,20,’’,’’)

（10）.写出sql语句，修改员工张四的住址为南京（2分）

UPDATE employee SET address = ‘南京’ WHERE NAME = ‘张四’

1.查询所有图书记录、查询所有借阅记录、查询所有读者信息，采用字段选择和通配符选择！

SELECT * FROM book

SELECT * FROM reader

SELECT * FROM check_out

2.查询图书馆中的书籍都有哪些出版社？

SELECT DISTINCT b_publish FROM book

3.查询出版日期在2008年至2010年之间的所有图书！

SELECT * FROM book WHERE b_pubdate BETWEEN ‘2008’ AND ‘2010’

4.查询部门是财务部、人事部、培训部的读者信息！

SELECT * FROM reader WHERE r_dep IN(‘财务部’,’人事部’,’培训部’)

5.查询所有姓张的读者详细信息!

SELECT * FROM reader WHERE r_name LIKE ‘张%’

6.查询所有未归还图书的借阅记录详情！

SELECT * FROM check_out WHERE return_date IS NULL

7.查询读者中人事部的读者有多少个、查询作者姓李的图书共有多少本！

SELECT r_dep,COUNT(r_code) FROM reader WHERE r_dep = ‘人事部’ GROUP BY r_dep

SELECT b_author,COUNT(b_code) FROM book WHERE b_author LIKE ‘李%’ GROUP BY b_author

8.查询《幻城》这本书总计价格是多少？（建议 数据录入的时候有不少于三本《幻城》）

SELECT SUM(b_price) FROM book WHERE b_name = ‘《幻城》’

9.查询《幻城》这本书平均价格是多少？

SELECT AVG(b_price) FROM book WHERE b_name = ‘《幻城》’

10.查找最贵的一本《幻城》的信息 ！

SELECT MAX(b_price) FROM book WHERE b_name = ‘《幻城》’

11.查询借阅日期在2011年10月的前3条记录

SELECT * FROM check_out WHERE borrow_date LIKE ‘%2011-10%’

12.查询所有图书并按出版日期排序、查询2011年的全年借阅记录，并按借阅日期倒序排序

SELECT * FROM book ORDER BY b_pubdate DESC

13.统计读者群体中各个部门的人数

SELECT r_dep,COUNT(r_code) FROM reader GROUP BY r_dep

14.统计2010年的借阅记录，查看每个图书编号都被借出去过多少次，并按照这个次数从大到小排序，以便了解书籍的畅销程度!

做热榜

SELECT b_code,COUNT(b_code) FROM check_out WHERE borrow_date

LIKE ‘%2010%’ GROUP BY b_code ORDER BY COUNT(b_code) DESC

15.统计读者群体中各个部门的女性群体数量

SELECT r_sex,r_dep,COUNT(r_code) FROM reader GROUP BY r_sex,r_dep

16.查询那本书被哪个读者在什么时间借过在什么时间还的

SELECT * FROM book,reader,check_out

WHERE book.b_code = check_out.b_code AND check_out.r_code= reader.r_code

SELECT b.b_name,r.r_name,co.borrow_date,co.return_date

FROM book b,reader r,check_out co

WHERE b.b_code = co.b_code AND co.r_code= r.r_code AND co.return_date IS NULL

查询难度分为四种的

1.单表查询 条件单一

2.单表查询 条件复杂多

3.多表联合查询 条件单一

4.多表联合查询 条件复杂多

回顾一对多

联合查询 一对多 和 多对多

1.普通连接 WHERE 一方的主键=多方的外键

SELECT * FROM class c,student s WHERE c.id = s.c_id

2.内连接 INNER JOIN ON 一方的主键=多方的外键

SELECT * FROM class c INNER JOIN student s ON c.id = s.c_id

3.自连接 表自己连接自己 A表自己是一方 同时 也是多方 后面再讲

4.外连接 OUTER JOIN ON 一方的主键=多方的外键

​ 左外 LEFT JOIN ON

​ 表分成 左表和右表 单纯的左右

​ 效果 查询出左表的全部数据 和右表关系列相等的数据

SELECT * FROM class c LEFT JOIN student s ON c.id = s.c_id

​ 右外 RIGHT JOIN ON

​ 表分成 左表和右表 单纯的左右

​ 效果 查询出右表的全部数据 和左表关系列相等的数据

SELECT * FROM class c RIGHT JOIN student s ON c.id = s.c_id

CREATE TABLE qqnum(id INT(2) PRIMARY KEY AUTO_INCREMENT,num VARCHAR(10));

CREATE TABLE qqrole(id INT(2) PRIMARY KEY AUTO_INCREMENT,rname VARCHAR(10));

CREATE TABLE num_role(n_id INT(2),r_id INT(2));

关系列 n.id = nr.n_id AND nr.r_id = r.id

SELECT * FROM qqnum n,qqrole r,num_role nr

WHERE n.id = nr.n_id AND nr.r_id = r.id

知道 1008的会员身份有哪些？

SELECT * FROM qqnum n,qqrole r,num_role nr

WHERE n.id = nr.n_id AND nr.r_id = r.id AND n.num = ‘1008’

添加两个外键约束

ALTER TABLE num_role

ADD CONSTRAINT a1 FOREIGN KEY (n_id) REFERENCES qqnum(id);

ALTER TABLE num_role

ADD CONSTRAINT a2 FOREIGN KEY (r_id) REFERENCES qqrole(id);
