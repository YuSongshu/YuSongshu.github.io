索引

格式：存储字符串的变量名[下标值]，注意：从0开始

1.正向索引

char2 = ‘abc’
print(char2[2])

2.负向索引

print(char2[-2])

3.索引超出范围

报错：IndexError: string index out of range
print(char2[-5])
print(char2[6])

切片

格式：[起始值：结束值：步长]
步长默认为1，结束值不包括(包前不包后)，[起始值，结束值)
range(起始值，结束值，步长)

正向切片

char2 = ‘hello’
print(char2[0:3])
print(char2[0:3:2])

负向切片

print(char2[-1:-4:-1])
print(char2[-1:-4:-2])

成员变量 in not in

in判断在，输出True
not in 判断不在，输出True
