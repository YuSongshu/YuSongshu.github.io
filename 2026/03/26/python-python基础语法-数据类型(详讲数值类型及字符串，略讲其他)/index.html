04_数据类型(详讲数值类型及字符串，略讲其他)——

查看数据的类型：数据类型的关键字 => type(数据/变量名)

数据类型

可变数据类型

列表 => list()

集合 => set()

字典 => dict()

不可变数据类型

不可变的数据类型，修改会创建新的对象

输出：

所以少改不可变数据类型（ 频繁创建新对象 + 浪费内存 + 速度变慢）

要频繁修改 → 用 list（列表）（list 是可变类型，原地修改，不建新对象，速度极快）

数值类型

整数型 => int

浮点型(小数) => float

布尔型 => bool => 特殊的数值型

布尔型:True/False –>python中的关键字

True代表的特殊数字是1；False代表的特殊数字是0

注意点：首字母一定是大写

复数 =>complex (了解)

格式：a+bj

复数由：实部a+虚部b(j/J)组成

字符串 =>str

不是数值类型

所有被引号包围的数据都是字符串
