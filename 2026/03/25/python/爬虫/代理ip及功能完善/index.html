timeout

timeout参数用于指定请求的超时时间，它告诉requests在等待服务器响应多久后停止等
待。timeout参数可以防止程序在等待服务器响应时无限期地阻塞。
response = requests.get(url, timeout=1.0)

retrying

使用超时参数能够加快我们整体的请求速度，但是在正常的网页浏览过程中，如果发生
速度很慢的情况，我们会做的选择是刷新页面。
在代码中，怎么刷新请求呢？
安装 retrying ：

pip install retrying -i https://mirrors.aliyun.com/pypi/simple

使用：
from retrying import retry
@retry(stop_max_attempt_number=3)
