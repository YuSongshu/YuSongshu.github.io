cookie

Cookie 是一个 “小型文本文件”，是某些网站为了辨别用户身份，进行Session跟 踪而储存在用户本地终端上的数据（通常经过加密），由用户客户端计算机暂时或永 久保存的信息。
​ 是什么？小型文本文件
​ 为什么是小文件，不是大文件？

核心功能

1.身份识别：保存登录状态，避免重复认证。

2.偏好存储：记录用户设置（如语言、主题）。

3.会话保持：临时保存购物车等状态信息。

4.行为跟踪：分析用户浏览习惯

url转代码

偷懒方法：
​ 所有偷懒方法都基于你掌握了的前提。
​ 如果自己还不会添加的，一定是自己能掌握添加之后，再使用这个。

具体步骤：
1. 打开网站：https://www.lddgo.net/convert/curl-to-code
2. 定位正确请求
3. 右键点击请求 =》点击复制 =》点击复制位 cURL(bash)
4. 回到工具网站
5. 左上角更换语言位Python
6. 将复制的内容粘贴到中间黑框框
7. 点击转换
8. 点击复制
9. 粘贴到本地 py 文件

注：

快捷键：
    全选：ctrl+a
    复制：ctrl+c
    粘贴：ctrl+v
    剪切：ctrl+x
    撤销：ctrl+z
    注释：ctrl+/
    搜索：ctrl+f
    替换：ctrl+r
    快速复制：ctrl+d

笔趣阁网站：
​ https://www.bqg78.com/
​ 需求：登录
​ 1. 一定要先登录之后再定位登录请求
​ 目的是定位请求，只要发送了登录请求就行【不管正确与否】
​ 2. 选择错误账号登录
​ 因为登录成功会跳转到成功页面，会对新的页面发起请求，需要分析的请求更多。

定位请求：
    1. 搜索
    2. 排除【让抓到的正确的包越少越好】
        - 点击左上角【圆圈斜杠】清楚网络日志
        - 再次对目标行为发起请求
    3. 负载参数
        如果是做登录【要携带用户名和密码 不会在?后面显示，一定会有表单数据】
    4. 排除【不可能的文件 图片、视频、音频、字体、css、js】
        \u52ff\u5c0f\u609f unicode 编码
        https://www.lddgo.net/convert/string-unicode

        查询字符串参数 params
        表单数据 data
        确定请求是否正确，是与你自己目标的数据对比。

session 干嘛的？
